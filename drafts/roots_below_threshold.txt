# ternus 2 员（external / internal）
#   2026-08-26 从 4 员跌下来：alternate 迁去 alter-other、international 迁去 nasci，
#   两处迁移都词源正确。extern / intern 不在考研词表。
#   eternal 看似能补，实为 aeternus ← aevum（时代），与 externus/internus 不同源。
#
# tangere 2 员（attain / contact）
#   intact ← intactus = in- + tactus ← tangere，**真能补，在 latin_remaining 池中**，
#   下一批拉丁批写到它就能凑满 3 员。
#   tactic 看似能补，实为希腊 taktikos ← tasso（排列），与拉丁 tangere 无关。
#
# filum 2 员（profile / file）
#   filter 实为 filtrum（毛毡），不是 filum（线）。
#   affiliate 实为 filius（儿子），不是 filum——chunk84 的子代理已核。
#   filament 不在考研词表。
#
# peior 1 员（impair）
#   pessimistic 在池中，但 Wiktionary 只给到 pessimist + -ic，未直连 peior/pessimus，

#
# conciliare 1 员（reconcile）
#   council 看似能补，实为 consilium ← consulo（商议），与 concilium（集会）是两个词。

# hum-onomatopoeia 1 员（hum）
