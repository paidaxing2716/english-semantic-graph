relay	laxare（古法语 relaier ＝ re-（再）＋laier「放开、松手」← 拉丁语 laxare 松开；接力就是把手里的东西松开交给下一位。该族在词表内有 relay/relax/release/delay/lease 五词，语义都推得出：relax 再松开、release 松开放走、delay 放着不紧办、lease 把地松手交出去用。库中尚无此根，属新根）
rely	ligare（已建模词根 ligare，其 origin 即写「拉丁语 ligare 捆、绑住」；rely ← 古法语 relier ＝ re-＋ligare，本义「把自己拴到某物上」。该根现有成员 obligation/religion/religious/ally/alliance/alloy 六个，词表内还可补 rely/reliable/reliance/liable/league/rally，属补词而非新根）
repay	pacare（古法语 paier ← 拉丁语 pacare「使平息、抚平」← pax 和平；付钱本义是「把讨债的人安抚平」，故与 peace 同支。该族在词表内有 repay/pay/payment/peace/peaceful 五词。注意库中已建模的 pangere「拉丁语 pangere 钉入、缔结」是另一支，pact/compact/impact 属那边，不可混入；本族尚无根，属新根）
reply	plicare（已建模词根 plic，其 origin 即写「拉丁语 plicare 折叠」；reply ← 古法语 replier ← 拉丁语 replicare ＝ re-（往回）＋plicare，本义「折回去」，答话就是把话折回给对方。该根现有成员 application/applicable/complicate/complication/implication/employ/employee/employer/exploit/display 十个，属补词而非新根）
river	ripa（古法语 riviere ← 通俗拉丁语 riparia ← 拉丁语 ripa 河岸；河就是两道岸之间的水。该族在词表内有 river/arrive/arrival 三词，arrive ← 拉丁语 adripare「靠上岸」，推得出。注意库中已有 arrive，是按日耳曼型写的孤立词条 root_ids 为空，建 ripa 根时可一并接进去。另注意 rivus（小溪）是另一个拉丁词，rival/derive 属那一支，不要并进 ripa）
role	rotula（法语 rôle ← 古法语 rolle 卷成筒的羊皮纸 ← 拉丁语 rotulus / rotula「小轮、小卷」← rota 轮；演员的台词抄在卷轴上，那一卷就是他的戏份。该族在词表内有 role/roll/round/rotate/control/enroll/surround/around/rotary 九词，都推得出：roll 像轮子那样滚、round 轮子那样圆、control ＝ contra＋rotulus 拿副本对着查、enroll 记进名册那一卷。库中尚无此根，属新根，建根时宜用 rota 一支的拉丁词形）
roll	rotula（同 role 一族：古法语 roller ← 通俗拉丁语 *rotulare ← rotulus ← rota 轮。词表内共九词，见上条）
round	rotula（同 role 一族：古法语 roont / reond ← 拉丁语 rotundus ← rota 轮，本义「轮子那样的」。词表内共九词，见上条；around/surround 亦同支）
route	rumpere（已建模词根 rumpere，其 origin 即写「拉丁语 rumpere 打断、断裂 及其过去分词 ruptus」；route ← 古法语 route ← 通俗拉丁语 rupta via「劈开来的路」，即在林野里破开的一条道。该根现有成员 disrupt/abrupt/corrupt 三个，词表内还可补 route/routine/bankrupt/erupt，属补词而非新根）
royal	rex（古法语 roial ← 拉丁语 regalis ← rex 王，属格 regis。该族在词表内有 royal/royalty/reign/regime/region 五词，reign ← regnum 王权、region ← regio 王令所及的一片地，都推得出。注意库中已有同出印欧语 *reg- 的两支：rect「拉丁语 regere / rectus」与 regula「拉丁语 regula 木尺，来自 regere」，rex 是名词王一支，上报时需定夺是另立 rex 还是并入其中一支）
safe	salvus（古法语 sauf ← 拉丁语 salvus「完好无损的」。该族在词表内有 safe/safety/save/salvation/salute 五词，save ← 晚期拉丁语 salvare 使完好、salvation 保全下来、salute ← salutare 出自同支的 salus「安好」即问人安好，都推得出。注意 salary 来自 sal 盐，不属此族。库中尚无此根，属新根）
