### 第 9 列音标怎么写

英式 RP，斜杠包裹。**只能用库内这 46 个字符**，超出会被拦：

```
( ) . / a b d e f g h i j k l m n o p r s t u v w z · æ ð ŋ ɑ ɒ ɔ ə ɜ ɡ ɪ ʃ ʊ ʌ ʒ ˈ ˌ ː θ
```

即：非儿化（`/ˈdɒktə/` 不是 `/ˈdɑːktər/`）、用 `ɒ` 不用 `ɑː`（`/lɒt/`）、
用 `əʊ` 不用 `oʊ`、用 `e` 不用 `ɛ`、用 `r` 不用 `ɹ`。不要用组合变音符。

这批词多是 `over-` / `out-` 复合词，注意**主重音位置**：`overlook` 是
`/ˌəʊvəˈlʊk/`（动词，重音在后），`overpass` 是 `/ˈəʊvəpɑːs/`（名词，重音在前）。
名动异重的词按输入给的 pos 定重音。

### 落盘方式（这条必须照做）

**不要用 Write / 文件写入工具直接写 TSV。** 它会规范化行尾空白、把结尾的制表符吃掉，
尾列留空的行会从 8 列变成 7 列，而校验可能放行。写一个 Python 脚本按列表 join：

```python
rows.append([w, origin, native, zh, ex, concept, expansions, image])

```

落盘后自己跑，必须为 0：

```bash
awk -F'\t' 'NF!=8' drafts/sb_chunkNN.tsv | wc -l
```

## 各列的硬规则

### origin（列 2）

照输入的词源写，**不许编造**。库里有过编造的先例（`medal` 曾被写成「挂在胸前正中」）。

- 有明确链条就写链条：`plaster` → `古英语 plaster ← 晚期拉丁语 plastrum ← 古典拉丁语 emplastrum（膏药、敷布）`
- 借词写真实来源：`pamphlet` → `中古英语 pamphilet ← 中古法语，源自 12 世纪拉丁语情诗 Pamphilus 的俗称`
- **确实无定论就写明「更早词源不明」**，别硬凑。`zoom` 那类拟声词写
  `英语 zoom（拟声，19 世纪末见于记载）`即可。
- **origin 里绝不写别的词根的拉丁原形**——脚本会拿 origin 抽词元，写了会造成错误归属。

`decomposable_note` 由脚本按 origin 自动分流（日耳曼核心词 / 早期借词 / 法语借词 /
拉丁借词 / 希腊借词 / 经罗曼语回流），**你不用写**。

**但这意味着 origin 的措辞会决定另一个字段的分档，不只是给人看的。两条实测：**

1. **是借词就必须写 `←` 箭头。** 分流器只在「箭头后紧跟外语名」时才判借词。
   origin 里同时出现日耳曼词形与外语名却没有箭头，会落回默认档「日耳曼核心词」。
   实测栽过两次：`paralyze` 写成「部分借自法语 paralyser，部分由中古英语 paralysie
   ＋ -ize 构成」→ 判成日耳曼核心词。改成「…；paralysie ← 古法语 ← 希腊语
   paralusis（一侧松脱）」才对。
2. **纯词缀式 origin 会丢掉语源。** `optical` 只写「由 optic ＋ -al 构成」不含任何
   语言名，同样落回日耳曼档。要把词源链补到源语言：「由 optic ＋ -al 构成；
   optic 一支 ← 中世纪拉丁语 opticus ← 希腊语 optikos（与看有关的）」。

反过来，**外语名出现在「可能／一说／或与…有关／非拉丁」这类措辞里时，不写箭头是对的**
——分流器正是靠没有箭头来判定那不是来源。库里 bird / brain / howl / flock 都属此类。

### image（列 8）—— 只有 89 词需要

**最要紧的一列。** 中文具体场景，15–35 字，能在脑子里看见的画面，不是释义。

**硬规则：image 里不得出现列 4 中任何长度 ≥2 的中文义项。** 学习者看画面时单词和中文
都被遮住，必须只靠画面想起这个词。点名义项等于自泄答案。脚本会拦。

- 错：`plaster`，zh `石膏`，image `工人把石膏抹在墙上` ← 含「石膏」
- 对：`plaster`，zh `石膏/膏药`，image `白色粉末兑水成糊，抹上墙面后逐渐硬成平整一层`

### examples（列 5）

两句，各 5–12 词，句末句号。**要能体现该词的典型用法**，不是把词塞进通用句子。

- 错：`The pamphlet changed the situation.`（这就是被替换掉的模板）
- 对：`Volunteers handed out pamphlets outside the station.`

### concept（列 6）

`english phrase – 中文解释`，用短破折号 `–`（不是 `-` 也不是 `——`）。
写这个词的**核心概念**，一句能概括各义项的话。

- `pamphlet` → `a thin unbound booklet for spreading a message – 用来散发主张的薄册子`

### expansions（列 7）

列 4 有 2 个以上义项时必填。逐条写**某义项如何从核心画面推出**，`|` 分隔。

- `plaster` zh 是 `石膏/膏药`，则写
  `石膏：兑水成糊、干后硬成一层|膏药：同样是敷在表面的糊状物，只是敷在伤处`
